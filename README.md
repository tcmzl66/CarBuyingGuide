# 人生第一辆车 · 购车决策助手（B 站 Toy）

一个纯前端的交互式购车决策向导，帮助你在买人生第一辆车前，把「要不要买 / 我的需求 / 能承受的预算 / 怎么选 / 怎么提」一步步想清楚。

> 内容框架整理自 B 站 UP 主 **所长Wy**《如何买人生第一辆车？》([BV15cH56sE1j](https://www.bilibili.com/video/BV15cH56sE1j)) 及其《购车指南参考图表》。本工具只做决策梳理，**不推荐具体车型、不替代实车体验**。

## 功能流程

1. **要不要买** —— 灵魂三问 + 持有成本估算（落地价 / 年用车成本 / 年均持有）
2. **梳理需求** —— 七个需求维度，按场景勾选并排优先级（必须 / 优先 / 更好）
3. **定预算** —— 稳定结余法：输入每月稳定可支配金额，反推能承受的车价区间与月供额度
4. **选车标准** —— 能源形式 / 底盘 / 动力 / 空间 / 安全 / 辅助驾驶 / 智能座舱，怎么看 + 怎么试
5. **谈价 · 验车** —— 砍价、报价单、合同九查、提车验车打勾清单
6. **我的方案** —— 汇总以上填写内容，可复制或导出为 `.txt`
7. **附：事故处理速查** —— 保命 / 取证 / 报警 / 定损

## 数据与隐私

- 目前无服务器，用户填写的内容保存在浏览器本地 `localStorage`，下次打开自动续填。
- 存储层封装在 [`storage.js`](./storage.js) 的 `Store` 对象中（`get/set/save/reset/hasAny`）。后续接入服务器或 B 站 Toy 云存储 SDK 时，只需替换其实现、保持同样接口，业务代码无需改动。

## 技术栈

原生 HTML / CSS / JavaScript，零依赖、零构建。文件说明：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 入口骨架（保持 < 1 MB） |
| `styles.css` | 样式（B 站蓝粉主题、移动端优先） |
| `data.js` | 全部内容与决策框架数据 |
| `storage.js` | localStorage 持久化层 |
| `app.js` | 步骤向导渲染与交互逻辑 |

所有资源引用均为**相对路径**，符合 Toy 在 `/toy/<slug>/` 子路径下运行的要求。

## 本地运行

任意静态服务器均可，例如：

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```
